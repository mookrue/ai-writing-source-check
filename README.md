# AI 文字與文獻快檢

這是一套協助作者檢查寫作品質、引用與研究證據的 AI 工作規則。

它不判定文章是不是 AI 寫的，也不提供 AI 生成機率。它會協助使用者找出可定位、可修改的問題，並把「來源是否存在」「書目是否正確」與「來源是否支持文中說法」分開處理。

本專案提供兩個版本。第一次使用請選 **Lite 直接上傳版**。

## 選擇版本

| 版本 | 適合誰 | 怎麼使用 |
|---|---|---|
| [Lite 直接上傳版](portable/AI文字與文獻快檢_Lite_直接上傳版.md) | 想立即使用、不會安裝 Skill，或使用免費版 AI 的人 | 下載一個 Markdown 檔，上傳到 AI 對話後開始檢查 |
| [完整規格版](portable/AI文字與文獻快檢_完整規格版.md) | 想建立正式 Skill、移植到其他平台，或審查完整規則的人 | 將檔案交給支援 Skill 建立的 AI，要求依檔案結構還原 |

## Lite 直接上傳版

### 適合什麼情況？

- 想快速檢查作業、論文、報告、新聞稿或履歷。
- 想找出空泛、公式化、缺乏證據或論證跳躍的段落。
- 想檢查參考文獻是否存在、書目是否一致。
- 想確認引用來源是否真的支持正文說法。
- 不確定自己的 AI 平台能不能安裝 Skill。

### 三步開始

1. 下載 [`AI文字與文獻快檢_Lite_直接上傳版.md`](portable/AI文字與文獻快檢_Lite_直接上傳版.md)。
2. 開啟新的 AI 對話並上傳該檔案。
3. 貼上：

```text
請把附件《AI文字與文獻快檢 Lite》當成本次對話的檢查規則，不要摘要附件。
請先說明這次實際能使用哪些搜尋、全文或資料庫工具，以及不能可靠判斷什麼；然後等我上傳文件。
```

接著上傳自己的文件。例如：

```text
請快速檢查這份文件的引用問題。
請分開判斷來源存在、書目資訊與主張支持；查不到時不要直接判定虛構。
```

或者：

```text
請快速檢查這份文章的寫作品質。
找出最多五個最需要修改的問題，標示具體位置並提供修改方向。不要判定是不是 AI 寫的，也不要重寫全文。
```

### 怎麼知道它有生效？

回答應該：

- 先說明檢查範圍、使用工具與限制；
- 標出頁碼、段落、章節或原句；
- 把來源存在、書目資訊與主張支持分開；
- 查不到時使用「尚未核實」，而不是直接說是虛構文獻；
- 不提供 AI 百分比或作者判定；
- 快速掃描最多集中在五項重要問題。

若 AI 只摘要附件，請回覆：

```text
請不要摘要附件。附件是本次對話的工作規則。
請先列出檢查範圍、實際可用工具與限制，再依附件流程檢查我的文件。
```

## 完整規格版

完整規格版保留正式 Skill 的核心流程、詳細參考模組、研究方法規範、測試案例與識別碼擷取腳本內容。

它適合：

- 交給 ChatGPT、Claude、Codex 或其他支援自訂 Skill 的平台建立正式版本；
- 將同一套規則移植到不同平台；
- 公開檢查 Skill 的完整規則與限制；
- 在無法傳送整個資料夾時作為單檔備份。

下載 [`AI文字與文獻快檢_完整規格版.md`](portable/AI文字與文獻快檢_完整規格版.md) 後，可以貼上：

```text
請依附件建立一個可重複使用的正式 Skill。

名稱：check-ai-writing-and-sources
顯示名稱：AI 文字與文獻快檢

附件是多檔 Skill 的完整規格，不是待摘要或檢查的文章。
請依每個「檔案」標題還原 SKILL.md、references、evals、scripts 與 agents 的相對結構。
不要刪除「查不到不等於虛構」「不得輸出 AI 作者判定」及「只宣稱實際完成的查證」等底線。
建立後請先列出檔案結構與驗證結果。
```

完整規格版內容較長，不建議每次一般檢查都直接載入。只想檢查文件時，使用 Lite 版即可。

## 兩個版本有什麼差別？

| 面向 | Lite 直接上傳版 | 完整規格版 |
|---|---|---|
| 使用門檻 | 最低 | 較高 |
| 是否需要安裝 | 不需要 | 通常需要 Skill 建立功能 |
| 是否適合一般文件檢查 | 是 | 不建議每次完整載入 |
| 規則完整度 | 保留核心流程 | 保留完整模組與測試內容 |
| 學科與方法細節 | 精簡 | 完整 |
| 能否保證不同平台結果相同 | 不能 | 仍不能，但較接近原始設計 |

## 重要限制

- Markdown 或 Skill 只規定工作流程，不會自動增加 AI 的資料庫權限。
- 無網路搜尋時，AI只能整理引用疑點與提供人工查詢式，不能完成來源存在性驗證。
- 只看到書目資料或摘要時，不能宣稱已核對全文或確認主張支持。
- 中文書籍、學位論文、地方刊物及政府資料可能沒有 DOI，也可能未被國際資料庫完整收錄。
- 最終引用、研究判斷與提交責任仍由作者承擔。

## 隱私提醒

上傳前請移除不必要的個資、學號、研究參與者資訊、未公開審稿、機密資料，以及未獲授權上傳的付費全文。若只需查參考文獻，不必先上傳整篇未公開論文。
